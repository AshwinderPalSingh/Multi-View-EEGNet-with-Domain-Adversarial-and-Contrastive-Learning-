2. PREPROCESSING PIPELINE
================================================================================

File: eeg_preprocessing_core.py

Step 1: Raw EEG Loading
- PhysioNet: EDF format via MNE-Python
- BCI-IV 2a: GDF format via MNE-Python

Step 2: Bandpass Filtering
- PhysioNet: 4.0–38.0 Hz (4th order Butterworth)
- BCI-IV 2a: 0.5–30.0 Hz (targets mu 8-12 Hz and beta 13-30 Hz bands)

Step 3: Euclidean Alignment (EA)
- Reference: He & Wu, "Transfer Learning for Brain-Computer Interfaces", 2020
- Per-subject covariance whitening to reduce inter-subject distribution shift
- Alignment target initialized from first subject's first file
- Applied before feature extraction

Step 4: Epoching
- Window: 2.0 seconds post-cue
- PhysioNet: 320 samples at 160 Hz
- BCI: 500 samples at 250 Hz

Step 5: Multi-View Feature Extraction
Three parallel views are computed for each trial:

View 1 — Time Domain:
  Shape: (N, C, T) — raw filtered+aligned EEG
  PhysioNet: (N, 64, 320)
  BCI: (N, 22, 500)

View 2 — Frequency Domain (FFT Spectrum):
  Shape: (N, C, F) — magnitude spectrum in dB scale
  PhysioNet: (N, 64, 161)
  BCI: (N, 22, 251)
  Computed via torch.fft.rfft, converted to dB (10*log10)

View 3 — Band Power (ERD/ERS Features):
  Method: fft_segments (8 temporal segments)
  Shape: (N, C, B) where B = num_bands * num_segments
  PhysioNet: (N, 64, 16) — 2 bands × 8 segments
  BCI: (N, 22, 16) — 2 bands × 8 segments
  Bands: mu (8-12 Hz), beta (13-30 Hz)
  No gamma (disabled by default)

Step 6: Saving
- Format: NumPy .npy arrays (memory-mapped)
- Files: all_time_X.npy, all_freq_X.npy, all_bands_X.npy, all_y.npy, all_subjects.npy
- Metadata: prepared_meta.json

3. MODEL ARCHITECTURE
================================================================================

File: phase2.py — Class: EEGNet (custom multi-branch, NOT standard EEGNet)

OVERVIEW:
Multi-branch architecture processing three parallel EEG views (time, frequency,
band power) through separate processing stems, fusing them via learned attention,
and classifying through a temporal convolutional network.

--- STEM PROCESSING ---

Time Stem (EEGNet-style Conv2d factorization):
  Block 1 — Temporal Conv: Conv2d(1, H, (1, K)) where K ≈ 0.25*fs
    - PhysioNet: K=40 (250ms at 160Hz)
    - BCI: K=63 (252ms at 250Hz)
    - Followed by BatchNorm2d
  Block 2 — Depthwise Spatial Conv: Conv2d(H, H*D, (C, 1), groups=H)
    - D=2 (depth multiplier)
    - Learns CSP-like spatial filters
    - Followed by BatchNorm2d, AvgPool2d(1,4), Dropout
  Block 3 — Separable Conv:
    - Depthwise: Conv2d(H*D, H*D, (1,16), groups=H*D)
    - Pointwise: Conv2d(H*D, H, 1)
    - Followed by BatchNorm2d, ELU, AvgPool2d(1,8), Dropout

Frequency Stem (same structure as Time Stem):
  - Same Conv2d factorization but with smaller temporal kernel (K/2)
  - Processes FFT magnitude spectrum

Band Stem (lighter — Conv1d):
  - Conv1d(C, H, kernel_size=1) → HybridNorm → GELU → Dropout(0.5*dropout)

--- BRANCH PROCESSING ---

Each stem output feeds into a MultiScaleBranch:
  - Multi-scale 1D convolutions (kernel sizes 3, 5, 7)
  - Channel projection to branch_channels
  - SEBlock (Squeeze-and-Excitation) channel attention
  - TemporalAttention
  - Temporal interpolation to uniform length (fuse_length=96 for time/freq, 16 for bands)

--- CROSS-ATTENTION ALIGNMENT ---

TemporalCrossAttention:
  - Band features serve as keys/values
  - Time+freq features serve as queries (learned alpha weighting)
  - Aligns static band power information with dynamic temporal positions
  - query_alpha_logit: learnable parameter for time vs freq query balance

--- FUSION ---

BranchFusion:
  - Concatenates 3 branches along channel dimension
  - Learned attention weights per branch (prevents branch collapse)
  - Projects to fusion_channels via Conv1d
  - Entropy regularization to prevent single-branch dominance

Post-fusion: SEBlock for channel attention

--- TEMPORAL CONTEXT ---

ResidualTCNBlock stack:
  - tcn_depth=3 layers
  - Dilations: [1, 2, 4]
  - Each block: Conv1d → HybridNorm → GELU → Dropout → Conv1d → HybridNorm → SEBlock
  - Skip connections with DropPath

--- CLASSIFIER HEAD ---

  - AdaptiveAvgPool1d(pool_out=6)
  - Flatten → Dropout(dropout) → Linear(fusion_channels * pool_out, num_classes)

--- NOVEL COMPONENTS (attached to backbone) ---

SubjectAdversarialHead (DANN):
  - GradientReversalLayer (lambda=1.0, pure sign flip)
  - Linear(features, hidden) → ReLU → Dropout(0.3) → Linear(hidden, num_subjects)
  - Single hidden layer (sufficient for 7-9 subjects)

ContrastiveProjectionHead (SupCon):
  - Linear(features, features) → ReLU → Linear(features, 256)
  - L2 normalized output for SupConLoss

--- MODEL SIZE ---

With hidden_channels=32, D=2 (BCI setting):
  - branch_channels = 64
  - fusion_channels = 128
  - Estimated ~50K-80K parameters

With hidden_channels=64, D=2 (PhysioNet setting):
  - branch_channels = 128
  - fusion_channels = 256
  - Estimated ~150K-200K parameters

--- NORMALIZATION ---

ChannelNorm: Per-sample, per-channel z-normalization (reduces cross-subject amplitude shift)
HybridNorm1d: 0.5 * BatchNorm + 0.5 * LayerNorm (combines batch statistics with sample stability)

4. TRAINING CONFIGURATION
================================================================================

File: train.py

--- OPTIMIZER ---
AdamW with differential weight decay:
  - Backbone: WD=0.02
  - Classifier head: WD=0.05 (5x multiplier)
  - Head LR multiplier: 0.5x base LR

--- LOSS FUNCTION ---
Primary: FocalCrossEntropy(gamma=0.5, label_smoothing=0.05)
  - Class weights: computed from class distribution (all 1.0 for balanced BCI)
Auxiliary 1: DANN domain loss (cross-entropy on subject labels, weighted by dann_lambda)
Auxiliary 2: SupConLoss (supervised contrastive, temperature=0.07, weight=0.05)
Auxiliary 3: Branch entropy regularization (-0.005 * fusion_entropy - 0.002 * band_attn_entropy)

--- SCHEDULER ---
Cosine annealing with warm restarts (cosine_restarts)

--- REGULARIZATION ---
- Dropout: 0.50 (progressive scaling: 0.6+0.4*progress)
- DropPath: 0.12 (stochastic depth)
- Weight decay: 0.02 (backbone), 0.05 (head)
- Label smoothing: 0.05
- Max gradient norm: 1.0 (gradient clipping)
- EMA decay: 0.9995

--- AUGMENTATIONS ---
Progressive 3-phase scheduling:
  Phase 1 (epoch ≤ warmup): aug_scale=0.1
  Phase 2 (warmup < epoch ≤ warmup+rampup): linear 0.1→1.0
  Phase 3 (epoch > warmup+rampup): aug_scale=1.0

Augmentation types:
  - Temporal shift: prob=0.3, max_ratio=0.05
  - Random scaling: prob=0.3, range=[0.85, 1.15]
  - Gaussian noise: prob=0.40, std=0.03
  - Time masking: prob=0.3, ratio=0.1, 1 mask per sample
  - Channel dropout: prob=0.15, ratio=0.15
  - Band-stop noise (FFT domain): prob=0.3 (in freq_aug, disabled in v16)
  - Phase perturbation (FFT domain): prob=0.3 (in freq_aug, disabled in v16)
  - CutMix: DISABLED in v16 (corrupts temporal EEG structure)
  - Mixup: DISABLED (harms EEG signals)

--- DANN SCHEDULE ---
Sigmoid ramp from 0 to max_lambda after warmup:
  - dann_lambda = 0.03 (max value)
  - dann_warmup = 15 epochs
  - GRL lambda = 1.0 (pure sign flip, no scaling)
  - Loss contribution = dann_lambda_val * CE(subject_logits, subject_labels)

--- EARLY STOPPING ---
  - Metric: val_auc (maximized)
  - Patience: 80 epochs
  - Min delta: 1e-4

--- INFERENCE PIPELINE ---
1. Select best model (EMA preferred > SWA > base)
2. AdaBN: Reset BatchNorm stats using calibration subject data
3. Temperature scaling: Learned on validation logits via LBFGS
4. MC-Dropout: 10 forward passes with dropout enabled
5. Test-Time Augmentation (TTA): 15 passes with noise+shift
6. Final prediction: averaged softmax probabilities

5. CROSS-VALIDATION SCHEMES
================================================================================

PhysioNet (5-fold subject k-fold):
  - 109 subjects split into 5 folds (~22 subjects each)
  - Inner split: 1 val subject, 1 calib subject from train pool
  - Train: ~85 subjects, Val: ~1 subject, Calib: ~1 subject, Test: ~22 subjects

BCI-IV 2a (9-fold Leave-Two-Subjects-Out):
  - 9 subjects, 9 folds (each subject tested once)
  - Fold k: Test=S[k], Val=S[k+1], Train=remaining 7
  - Example: Fold 1: Test=S1, Val=S2, Train=S3-S9
  - Calibration subject = validation subject (for AdaBN)
  - Full 288 trials per subject used for testing
  - Subject leakage validation: train∩test=∅, train∩val=∅, val∩test=∅

9. NOVEL CONTRIBUTIONS
================================================================================

1. MULTI-VIEW EEG FUSION WITH DANN (Novel):
   No prior BCI-IV 2a work combines time+freq+band-power views through learned
   multi-branch architecture with domain adversarial training. Standard approaches
   use CSP+LDA, single-view CNNs, or EEGNet alone.

2. DANN + SUPCON JOINT REGULARIZATION (Novel):
   DANN pushes features to be subject-invariant (domain adaptation).
   SupCon pushes features to be class-clustered (contrastive learning).
   These work in productive tension — novel regularization strategy for EEG-BCI.

3. EUCLIDEAN ALIGNMENT + DEEP LEARNING (Semi-Novel):
   EA (Riemannian preprocessing) combined with multi-view deep learning is
   underexplored. Most EA papers use CSP/traditional ML.

4. UNIFIED INFERENCE PIPELINE (Semi-Novel):
   EMA checkpoint → AdaBN → Temperature Scaling → MC-Dropout → TTA
   as a complete system is a contribution.

5. TEMPORAL CROSS-ATTENTION FOR BAND ALIGNMENT (Novel):
   Dynamic cross-attention aligning static band-power features with temporal
   positions from time/freq branches. Learnable query interpolation (alpha).
